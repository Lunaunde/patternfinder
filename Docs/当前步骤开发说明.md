# 当前步骤：识别与存储

开发分支：`chatgpt-dev`，起点为 `artificial_dev` 的 `b484649`。

已接通拍照实景、中央照片入场、圆形转译、新素材飞入、重复与失败下移丢弃、满库计数反馈。素材库最多 14 张，栏内一次展示约 7 张，通过左右滑动浏览，按具体素材 ID 判重，保存于当前 Level 实例。笔记本使用近满高的居中书图与下方可折叠素材栏，目标图仅用于编辑器定位，运行时显示实际玩家碎片。关卡配置、文案数据及尚待手机验证的帧率候选设置见 [笔记本与关卡配置](笔记本与关卡配置.md)。

**操作**

- 触屏：按住左侧摇杆移动取景框，另一只手点击右侧相机。松开取景操作会结束取景。
- 桌面：按住空格取景，方向键移动，Enter 或右侧相机拍照。空格松开后结束取景。
- 拖动花园空白区域可横向浏览；素材栏右上箭头用于展开、收起。
- 在素材栏内快速左右拖动可浏览其他卡片，不使用分页按钮。
- 长按卡片 0.25 秒，或明显向上拖动，可拿起卡片。拖到白色区域会变暗并显示“松手删除”，松手才删除；移回素材栏则取消删除。
- 拿起卡片后拖入其他卡片之间，会显示插入线；松手按插入位置换位，其他卡片保持相对顺序。拖到素材栏两侧边缘可自动滚动，支持移动到当前未显示的卡片之间。
- 拖到普通空白区域松手，卡片回到素材栏。窗口失焦、缩放、折叠素材栏或进入拍照流程也会取消拖动，不会删除。
- 拍照期间冻结相机与取景框移动，连续点击不会启动另一条流程。动画期间松手，结束后恢复观察状态；保持按住则恢复取景。

**检测与识别**

`FrameInsideRate` 沿用原公式。`Detected` 每次移动都重新选择评分最大的有效重叠目标；进入、退出、吸附力、强制居中阈值和原位移顺序保留。拍照成功使用独立的 `Config.PHOTO_SUCCESS_RATE = 0.8`，不以 `Detected` 状态直接判定成功。

拍照瞬间固定世界取景矩形、目标、评分，并只调用一次候选选择，固定所选素材 ID、名称和纹理引用。动画期间修改候选配置或松开取景都不会改变本次结果。独立 SubViewport 只渲染世界 layer 1；Frame 使用 layer 2，UI 在 CanvasLayer 中。返回的是冻结照片，不会被后续拍摄覆盖。

**界面适配**

`UILayer/AspectRatioContainer/UIRoot/DesignRoot` 将 2430×1080 的设计内容等比缩放并居中。项目 stretch aspect 使用 `expand`，由容器处理实际窗口比例；背景随视口覆盖屏幕，相机横向边界保持非负。

**素材配置**

同一张植物原型图现在可以对应多种纹样，每次拍照生成其中一张。在 PatternObject 的 Inspector 展开 `Variants`，添加多个 `PatternVariant` Resource，各配置 `MaterialId`、`MaterialName`、`MaterialTexture`。纹理既可使用独立 PNG，也可使用 AtlasTexture 从素材大图裁剪。不同变体使用不同 ID；同 ID 在当前 Level 库存中表示同一具体素材。当前调试原型已改为忍冬藤，配置 `honeysuckle-unit`（忍冬单体纹）和 `honeysuckle-variant`（忍冬卷叶纹）。

候选默认等概率选择，每个原型实例第 5、10、15……次有效识别优先抽取当前库存尚未收集的候选；全部已收集则恢复普通随机。重复结果和满库结果仍属于有效识别，评分不足或没有有效候选不会累计次数。候选 ID 重复不会提高其概率；空 ID、缺失或无效纹理会被排除。选择阶段不会提前入库，新素材完成飞入动画后才由 Bar 入库。计数与库存均属于当前运行实例；底层截图异常不会回滚已发生的识别计数。

PatternObject 只保留 `Variants` 作为纹样配置入口。只需要一种纹样时添加一个候选；没有有效候选时识别失败，不累计保底次数。新增原型时，在入树前设置原型贴图，以便现有碰撞形状按其大小创建。

**素材库样式**

拍立得使用 `Assets/Texture/gardern/拍立得4.png` 第一行第三张，裁剪区域为 `(968,93,402,514)`；保留白色手绘边框，覆盖原黑色照片占位区，实景照片等比显示。成功转译的整张卡与库存卡都使用 `Assets/Texture/ui/garden_cardbar_card_normal@3x.png`，通过 shader 清除其自带示例纹样，保留蓝边、纸面擦痕、棕色分界线和绿色底部；不修改原 PNG。

圆形 shader 按照片像素计算半径，只扩大揭示范围，纹样尺寸保持固定，支持 AtlasTexture。成功时整张拍立得逐渐替换为真实纹样卡；失败时白纸照片区逐渐替换为涂鸦。库存卡将名称显示在绿色底部，空槽使用同一边框的淡化状态。

**本阶段采用的计划口径**

- 新素材先在中央完成转译，再进入素材栏。
- 当前库内已有相同 ID 或识别失败时丢弃，不占库存。
- 新卡入库时自动回到列表左端，从左侧插入第一位；已有卡片一起向右移一格。卡片控件和素材对象均复用，图案不变。
- 第 8–14 张可通过横向滑动浏览；第 15 张拒绝入库，`14/14` 抖动并保持高亮。
- 拖出的卡片仍计入库存，松手删除后才释放容量和素材 ID，之后可重新拍摄收集。删除和换位不改变其他卡片的内容。
- 当前存储为运行期库存；笔记本基础拼接已接入，特殊关卡的第二/第三次指定概率规则和退出游戏存档仍属于后续工作。
